Règles de détection

            

                Une règle est une expression régulière .NET (sans tenir compte de la casse) qui reconnaît un nom de fichier et en extrait des groupes nommés :
                (?<title>…), (?<year>…), (?<season>…), (?<episode>…) pour les films et séries ;
                (?<artist>…), (?<album>…) pour la musique (en complément des tags).
                Les règles sont essayées dans l'ordre : la première qui reconnaît le fichier l'emporte. Un film exige title, une série exige episode.
                « Nom » s'applique au nom du fichier sans extension (et sans suffixe de langue pour un sous-titre) ; « Chemin » s'applique au chemin relatif d'un dossier déposé, avec « / » (ex. Série/Season 2/05 - Titre).
            

            

            

            

                
                
                
                
            


            
Tester

            
Un nom ou chemin par ligne (ex. Breaking.Bad.S02E05.720p.mkv, ou Dune (2021)/Dune.fr.srt). Les règles testées sont celles ci-dessus, même non enregistrées. Les fichiers listés ensemble sont analysés ensemble : un sous-titre est associé à sa vidéo.

            
            

                
                
            

            

            


            

                
Utiliser l'API (scripts, yt-dlp…)

            
Créez une clé API dans Tableau de bord > Clés API, puis : tous les champs hormis files sont optionnels ; type (music, movie ou series), artist, album, title, year, season remplacent ce qui est déduit du fichier. L'API range tout de suite, sans aperçu.

            
curl -X POST "http://SERVEUR:8096/MediaUploader/Upload" \
  -H "X-Emby-Token: VOTRE_CLE_API" \
  -F files=@"Titre.opus"
