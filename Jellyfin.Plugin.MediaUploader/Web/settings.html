Media Uploader : paramètres

L'envoi de fichiers se fait sur la page /MediaUploader/Ui (ouverte à tous les utilisateurs connectés), pas depuis cette page. Ici : réglages réservés aux administrateurs.

Utiliser l'API (scripts, yt-dlp…)

Créez une clé API dans Tableau de bord > Clés API, puis : Tous les champs hormis files sont optionnels ; artist, album, title, year remplacent ce qui est déduit du fichier.

curl -X POST "http://SERVEUR:8096/MediaUploader/Upload" \
  -H "X-Emby-Token: VOTRE_CLE_API" \
  -F files=@"Titre.opus"
